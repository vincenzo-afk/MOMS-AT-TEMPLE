# Character Bible

All characters are generated by `blender/scripts/assets_characters.py` from one parametric body (`tom/character.py: Body`) on the shared skeleton **SK_Humanoid_A**. Names are fictional Tamil names; roles are functional and not claims about historical offices. Clothing (veshti, saree with pallu, angavastram shoulder cloth, head towel, turban) is generic South Indian village dress and needs review against the cultural reference brief.

## Skeleton SK_Humanoid_A

```
root
└─ hips
   ├─ spine ─ chest ─┬─ neck ─ head
   │                 ├─ shoulder_L ─ upper_arm_L ─ forearm_L ─ hand_L
   │                 └─ shoulder_R ─ upper_arm_R ─ forearm_R ─ hand_R
   ├─ thigh_L ─ shin_L ─ foot_L ─ toe_L
   └─ thigh_R ─ shin_R ─ foot_R ─ toe_R
```

21 deform bones + `root` (non-deforming). Bone names are identical across characters so clips can be shared.

## Skinning

Weights are assigned while the mesh is built: each body part knows its bone chain and blends across joints within 5–7 cm (`chain_weights`). Skirts blend `hips` into both thighs, increasing toward the hem (up to 94 %), so long strides stretch the cloth rather than let the legs punch through. Checked in Workbench pose renders (`blender/scripts/review_character.py`) for walk, run, pickup, craft and talk.

## Status (honest)

Session 2 rebuilt every character to the reference sheet: bare torsos with chest and abdomen shapes, kachcha dhotis with separate leg sleeves, pleated veshtis, saree pallus, angavastram strips with woven border stripes, four-fingered hands with thumbs, toes, cheekbones, lips, brows, beards, topknots and accessories (pouch, necklace, tool belt, satchel, staff, wrist wraps, earrings, bangles). A runtime triplanar skin and cloth detail texture adds grain. Only the player GLB carries animation; NPCs reuse it by retargeting.

These are still **procedural characters**, not hand-modelled production art: no UV textures, simple faces without a facial rig, and cloth that stretches rather than simulates. A hand-modelled pass can replace any character file without code changes as long as it keeps SK_Humanoid_A.
